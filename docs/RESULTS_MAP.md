# From manuscript claims to computations

The authoritative manuscript is [paper.md](../manuscript/paper.md), rendered as [paper.pdf](../manuscript/paper.pdf). Its source and designated format hashes are recorded in [document_verification.json](../provenance/document_verification.json). The complete paper supersedes prior research-report and separate-companion drafts, which are not part of this release.

The scientific aim is harm reduction. The claims below concern computational estimates from existing data. No row represents demonstrated patient benefit. Primary comparisons, original decision rules and exploratory diagnostics retain their original roles.

## Commands and environment binding

Run `python -I -B src/release.py reproduce --inputs-root INPUTS --output-root NEW_RUN` to generate the entire map. [Reproduction instructions](REPRODUCING.md) distinguish that command from packaged-byte verification and intermediate reconstruction. The pinned environment is [requirements-lock.txt](../requirements-lock.txt); [source_data.json](../provenance/source_data.json) binds source versions/checksums; the generated run receipt binds code hashes, commands and actual outcomes.

Historical source corrections, alternate clock conventions and exploratory analyses remain documented in the scientific protocols. The release portability changes affect paths, provenance and isolation; they do not substitute a new research question or alter the frozen estimands. The [current verification record](../provenance/verification.json) reports tested scope and unresolved checks.
